## Goal (one sentence)

Port `escape.js`, `validators.js`, `date.js`, `detect-device.js`, `calendar.js`, `sanitize-html.js` → typed `web/src/lib/*.ts` with byte-identical golden parity against fixtures generated by running the legacy modules (D-012), including a 73-vector XSS corpus for the sanitizer (D-005, G-001).

## In scope

- `web/src/lib/escape.ts` — `esc` / `escapeHtml` / `escapeAttr` / `SafeHtml` / `raw` / `` html`` `` (port of `js/utils/escape.js`).
- `web/src/lib/validators.ts` — `isValidEmail` / `normalizeUSPhone` / `isValidUSPhone` / `isValidName` / `formatUSPhoneNational` (port of `js/lib/validators.js`; legacy `export default` shim dropped — named exports only).
- `web/src/lib/sanitize-html.ts` — `sanitizeHtml` / `htmlIsEmpty` / `renderRichText` / `richToPlain` (port of `js/lib/sanitize-html.js`; allowlist unchanged, D-005).
- `web/src/lib/calendar.ts` — `buildGoogleCalUrl` / `buildICS` / `downloadICS` / `addToCalendar` + `CalendarEvent` type (port of `js/utils/calendar.js`).
- `web/src/lib/date.ts` — `pad2` / `ymd` / `isoDate` / `todayISO` (port of `js/utils/date.js`; dependency of calendar — not on the S07 roadmap row by name, folded in here).
- `web/src/lib/detect-device.ts` — `isIOS` / `isAndroid` / `isDesktop` / `getPlatform` (port of `js/utils/detect-device.js`; dependency of calendar — same note).
- Golden tests: `web/tests/golden/{escape,validators,date,calendar,sanitize-html}.test.ts` (all via S05 `itGolden`).
- Unit tests: `web/tests/unit/{date,detect-device}.test.ts` (the clock/UA-dependent bits no fixture can pin).
- Capture harness: `web/tests/unit/capture-sanitize-html.test.ts` — CAPTURE=1-gated; regenerates the sanitizer fixture from the LEGACY module under jsdom.
- Fixtures: `web/tests/fixtures/{escape,escape-html-template,validators,date,calendar,sanitize-html}.json` — 254 vectors total, every one generated by RUNNING the legacy module (see NOTES.md for the exact commands).
