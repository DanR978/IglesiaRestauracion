## Steps

1. Read legacy `money()`; confirm its whole behavior is
   `(Number(n) || 0).toLocaleString('en-US', { style: 'currency', currency: 'USD' })`.
2. Generate fixtures by running the legacy module in Node (`tools/gen-fixtures.mjs`): 74 parity
   vectors (dollars input → legacy output), 9 non-numeric guard vectors, 2 approved-divergence
   vectors. Expected values come only from legacy.
3. Write `money.ts`:
   - `toCents(input: string | number)` → integer cents. Strings parse in exact decimal
     (optional sign, `$`, comma groups), rounding **half up at the cent, half away from zero**.
     Numbers convert via `String(x)` (shortest decimal repr — see the ICU landmine in NOTES).
     **Documented choice: throws** (`TypeError` on non-numeric, `RangeError` beyond safe cents) —
     no silent zeroes in a ledger.
   - `sumC(...cents)` → exact integer sum; throws on non-safe-integer input/overflow.
   - `toNumeric(cents)` → dollars number for DB `numeric` writes; `toCents(toNumeric(c)) === c`.
   - `formatUSD(cents)` → byte-identical to legacy output, **keeping** the legacy
     `Number(n) || 0` display guard (garbage → `$0.00`).
4. Golden test: `formatUSD(toCents(x)) === legacy money(x)` over `money-usd.json`;
   `formatUSD(garbage) === legacy money(garbage)` over `money-guards.json`.
5. Unit test: hand-computed `sumC` vectors; float-trap proof (`0.1 + 0.2` drifts, the cents path
   yields exactly 30 and `$0.30`; 1000×`$0.10` stays exact); rounding edges; round-trip;
   divergence fixture asserted to really diverge.
6. Copy deliverables into `web/` on `migrate/S08-money`, run the gate, open the PR.
